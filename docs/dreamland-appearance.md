# DreamLand 品牌与外观

DreamLand 是原 LeslieTavern 的新公开名称。SillyTavern 是聊天权威核心，AIRI 是集成的桌面陪伴前端。

## 四套风格

| 风格 | 布局与视觉 |
| --- | --- |
| 澄光 / Clear | 蓝灰与白色表面、窄导航栏、连续会话、柔和消息气泡。新用户默认使用。 |
| 月幕 / Moon | 顶部导航、夜色与暖金、宽松的阅读间距；也提供亮色。 |
| 梦境手帖 / Paper | 暖纸与墨绿、书架式会话、书页正文、用户消息左侧标记。 |
| 蔚蓝终端 / Blue | BA 灵感蓝白与青色、深蓝导航、细网格、微斜切筛选按钮、档案标题。 |

会话栏外观按钮可选择风格和亮暗模式。“设置 → 通用与外观 → 快捷设置”还提供装饰强度与场景背景。选择“背景”导航后，沿用 SillyTavern 的背景选择与本地导入；选择柔和遮罩或清晰氛围后显示场景。角色头像与首页人物图沿用已有角色卡，无须另一套资料库。正文和输入框始终使用稳定表面。

登录与用户空间入口沿用相同的本地风格。设置、记忆、朋友圈、剧情罗盘、语音、角色工坊及弹窗通过语义颜色共同变化。手机使用底部导航，聊天返回继续沿用原会话布局的历史处理。减少动态效果与减少透明度继续可用。

## 偏好、兼容与回退

外观仅保存到浏览器，不写入角色卡、JSONL、记忆或身份数据库。现有 `leslie.design.language` 中明确选择的 `cupertino` 或 `classic` 会保留。新用户和未知值使用 `dreamland`。

新偏好为 `dreamland.appearance.style`（clear/moon/paper/blue）、`dreamland.appearance.decoration`（subtle/full/off）、`dreamland.appearance.background`（off/soft/visible）。未知值经过验证回到默认，存储失败时仍可在当前会话使用。切换 Cupertino 或经典不会删除新偏好；重新选择 DreamLand 即可恢复。用户原来的 SillyTavern 主题与背景设置仍由原模块保存。

公开窗口、托盘、登录、PWA 图标、介绍文案和友好启动入口统一为 DreamLand。新增 `启动 DreamLand.cmd`，便携包另提供 `关闭 DreamLand.cmd`。旧入口仍可用。`leslie-*` 模块、Bridge v1、事件、包名、PID/stop 文件和数据路径保持稳定。仓库目录与 GitHub 仓库 URL 保持原名，避免失效链接和数据重定位。

本机数据继续使用项目 `data/`，便携包使用 `UserData/`，Electron 的指定数据根与 Cache 路径不变。便携监听仍为 `127.0.0.1:8127`。本地局域网设置、IP allowlist 与可信网络防火墙边界不因品牌改名改变。
