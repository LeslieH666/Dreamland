# DreamLand 界面与外观

应用统一使用 MomoTalk / 蔚蓝档案布局。SillyTavern 的聊天、角色卡、JSONL、群聊、World Info、Swipe 与模型适配仍由原模块负责。

## 一套布局，独立配色

桌面采用左侧联系人列表与底部功能导航，右侧为完整聊天或功能页。手机使用联系人/聊天视图切换与底部导航；故事线、现实线和对应的新建按钮始终可达。设置、朋友圈、工坊、背景和关于整页切换；记忆采用桌面宽抽屉，二级确认/编辑使用弹窗。导航保留消息节点与各页面草稿。

所有页面共用 BA 页头、卡片、表单、按钮与间距。外观设置保留明暗模式（亮/暗/跟随系统）、界面配色（桃粉/青瓷/鸢尾/暖砂/石墨）、首页场景显示、聊天背景显示、语言、减少动态和性能优先。配色不切换布局，也不替换素材。原生主题选择与颜色编辑不再作为新版 UI 的入口。

## 偏好迁移与回退

账号和演示空间仍分别使用 v1 的 `leslie/browser-preferences.json`。clear/moon/paper 自动映射到 blue，cupertino/classic 映射到 dreamland，full 装饰映射到 subtle（显示）；配色、明暗、背景、语言与其他交互设置保留。首次读取旧布局时将原始记录完整保留为 `browser-preferences.json.before-momotalk`，重复读取不覆盖备份。schemaVersion 不变，未知版本仍拒绝覆盖。回退到旧版代码时可在关闭应用后恢复此备份；普通保存仍保留 `.previous`。

登录页使用最近正式账号及所选账号的配色。未解密的外观提示仅包含白名单字段，其他偏好留在各自加密空间，演示设置不覆盖正式登录外观。自动明暗统一跟随系统。

账号头像在「设置 → 高级设置 → 解锁高级工具 → 完整界面设置 → 账号 → 更换头像」配置，和聊天 Persona 头像分别保存。加密空间的登录选择页使用公开默认图标，不在解密前读取个人头像；默认图标已改为随项目提供的 `/img/dreamland/icon-192.png`，避免引用不存在的旧文件。

## 本机素材与恢复

27 张原始图集部件、3 张原始场景和 7 张登记的着色适配直接随项目保存在 `public/img/blue-archive/bundled/`，无需额外安装。文件继承项目静态资源目录的读取权限，避免私有临时提取目录的 ACL 导致正常桌面进程读不到图片。旧 `local/` 仅保留本机历史预览，不再参与运行时加载。损坏时可按 [素材说明](../public/img/blue-archive/ASSETS.md)恢复。运行时仅访问同源本机资源，最多四张并发，每张失败后重试两次并绕过失败缓存；图片成功后立即使用。加载失败不锁定聊天。重新检测、网络恢复和返回前台可以再次读取失败项。

提示区分正在检测、就绪、部分读取失败、全部读取失败以及安装账目确实缺失；不再将网络超时笼统写成未安装。缺失项显示文件名。本机便携构建在修改输出目录前校验全包版本、文件类型与 SHA-256，再仅复制固定资源清单和安装账目，并校验输出；不携带本机预览。聊天与朋友圈导航只在原始图片可用时使用有对比度的底色；缺图时保留透明底和可见的备用图标，避免亮色状态下图标与底块同色。

来源、裁切、哈希与适配记录见 [素材账目](../public/img/blue-archive/sources.json)。本主题仍为非官方界面；原有权利声明见素材说明和应用关于页。

后续开发的 UI 库已下载到 `resources/blue-archive/ui-library/1.93.454564/`。这批大体积资源不参与启动或便携包加载，图片检索索引随源码保留，原始包及拆分图片通过 GitHub Release 分发，详见[界面素材库](../resources/blue-archive/README.md)。

## 运行边界

源码数据根和 Electron Cache 路径保持原值；便携数据根仍为包内 UserData，监听 `127.0.0.1:8127`、`listen: false`。局域网 allowlist 与可信网络防火墙边界未改动。历史四风格截图见 [历史预览](dreamland-preview.html)，不代表当前可选布局。

验证使用隔离的合成数据根 `Cache/MomoTalk-Unified-QA/data`；不会使用或提交真实聊天、账号偏好或游戏截图。
