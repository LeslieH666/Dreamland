# DreamLand 品牌与外观

DreamLand 是原 LeslieTavern 的新公开名称。SillyTavern 是聊天权威核心，AIRI 是集成的桌面陪伴前端。

## 四套风格

| 风格 | 布局与视觉 |
| --- | --- |
| 澄光 / Clear | 蓝灰与白色表面、窄导航栏、连续会话、柔和消息气泡。新用户默认使用。 |
| 月幕 / Moon | 顶部导航、夜色与暖金、宽松的阅读间距；也提供亮色。 |
| 梦境手帖 / Paper | 暖纸与墨绿、书架式会话、书页正文、用户消息左侧标记。 |
| MomoTalk · 蔚蓝 / Blue | 亮色使用 MomoTalk 粉色标题、灰色聊天底面与左右气泡，暗色使用暖炭灰与玫瑰色；使用本机 BA 原始标识、通用气泡、按钮、窗体和场景图片。 |

其他风格的会话栏外观按钮可选择风格和亮暗模式。BA 的外观和隐私入口统一放在“设置”；“设置 → 通用与外观 → 快捷设置”提供明暗模式、界面风格、装饰强度与场景背景。选择“背景”导航后，沿用 SillyTavern 的背景选择与本地导入；选择柔和遮罩或清晰氛围后显示场景。角色头像与首页人物图沿用已有角色卡，无须另一套资料库。正文和输入框始终使用稳定表面。

登录与用户空间入口沿用相同的本地风格。设置、记忆、朋友圈、剧情罗盘、语音、角色工坊及弹窗通过语义颜色共同变化。手机使用底部导航，聊天返回继续沿用原会话布局的历史处理。减少动态效果与减少透明度继续可用。

Blue 以 MomoTalk 为主界面，不替换角色卡或消息数据。首页使用夏莱工作室、暗色首页使用夜间办公室，登录使用基沃托斯城市背景；关闭装饰可以隐藏首页场景。按钮、记忆与次级确认继续复用游戏图片；设置、朋友圈、工坊、背景和关于改为主区域整页。气泡来自游戏通用聊天图集，按原边框参数伸缩；用户消息、暗色窗体和按钮纹理采用明确登记的着色适配。自由输入、Markdown、编辑、Swipe、故事/现实线及模型调用继续由原模块处理。

BA 会话栏顶部仅保留 MomoTalk 标识，朋友圈、创建角色、外观和隐私的重复入口隐藏。桌面底部导航保留在左侧会话栏，右侧显示整个功能页；手机显示导航上方的完整区域。聊天按钮恢复正在使用的会话，页面之间保留消息 DOM、输入草稿和工坊表单；浏览器返回可以退回前一个功能页。手动创建与 JSON 草稿交接复用原角色编辑器，并由原保存接口写入角色卡。切换其他主题时将原控件移回原来的抽屉或弹窗。

所有现代界面的手机聊天标题使用两行：第一行是返回、角色、记忆和更多，第二行固定显示故事线、现实线与对应的新建按钮。切换或新建期间禁用操作，避免尚未完成切线时创建到另一条线。群聊保留故事线。BA 手机页处理安全区和键盘视口；键盘出现时收起底部导航，给输入区留出空间。

## 偏好、兼容与回退

外观仅保存到浏览器，不写入角色卡、JSONL、记忆或身份数据库。现有 `leslie.design.language` 中明确选择的 `cupertino` 或 `classic` 会保留。新用户和未知值使用 `dreamland`。

新偏好为 `dreamland.appearance.style`（clear/moon/paper/blue）、`dreamland.appearance.decoration`（subtle/full/off）、`dreamland.appearance.background`（off/soft/visible）。未知值经过验证回到默认，存储失败时仍可在当前会话使用。切换 Cupertino 或经典不会删除新偏好；重新选择 DreamLand 即可恢复。用户原来的 SillyTavern 主题与背景设置仍由原模块保存。

公开窗口、托盘、登录、PWA 图标、介绍文案和友好启动入口统一为 DreamLand。Windows 日常启动只保留 `启动 DreamLand.cmd`，便携包另提供 `关闭 DreamLand.cmd`。旧品牌入口、重复启动脚本和上游更新入口已删除；开发环境使用 README 中的 npm 命令。`leslie-*` 模块、Bridge v1、事件、包名、PID/stop 文件和数据路径保持稳定。仓库目录与 GitHub 仓库 URL 保持原名，避免失效链接和数据重定位。

本机数据继续使用项目 `data/`，便携包使用 `UserData/`，Electron 的指定数据根与 Cache 路径不变。便携监听仍为 `127.0.0.1:8127`。本地局域网设置、IP allowlist 与可信网络防火墙边界不因品牌改名改变。
