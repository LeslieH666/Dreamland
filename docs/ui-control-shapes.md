# MomoTalk 控件形状补充规范

更新日期：2026-10-03。本文记录这一轮界面试改，保留 [原设计基线](design.md) 和 [原外观说明](dreamland-appearance.md)，不覆盖其内容。

## 按用途选择形状

| 用途 | 外形与状态 |
| --- | --- |
| 记忆、更多、新增、返回、关闭等日常图标工具 | 正圆；聊天页头使用 44 × 44 px，图标居中，状态点保持可见 |
| 确认、保存、应用配置、创建、发送等主要动作 | 保留游戏倾斜底板及蓝／黄色强调，文字和点击区域保持正直 |
| 设置分类、设置功能入口 | 恢复原有平面卡片、薄描边和小圆角，不使用游戏菜单的白边与凸起底边 |
| 首页快捷入口 | 规整小圆角矩形，浅灰底、白色描边、轻微底部阴影 |
| 取消和次要工具操作 | 规整中性矩形，不因位于设置页而自动变成异形 |
| 删除、重置等危险动作 | 警示文字及现有确认流程；外形不替代风险提示 |
| 多项互斥模式 | 保留分段控件和选中滑块，不逐项改成圆形 |

手机聊天头部的新建按钮带有当前线路文字，沿用第二行的规整矩形；记忆、更多和返回仍为圆形。设置里的输入框、下拉框和开关保留各自的操作形态。

2026-10-04 工坊修订：按用户最新要求，工坊底部操作栏统一使用游戏倾斜底板，弃用此处的规整凸起矩形。手动创建、下载和复制使用中性灰底，再审校使用蓝底，带入编辑器使用黄底；停止与放弃清空使用中性底和警示文字。倾斜仅应用于底板，标签和点击区域保持正直；窄屏换行，避免按钮被横向裁掉。

2026-10-04 试演区修订：三个场景切换使用薄边、无凸起阴影的统一切换按钮，选中状态通过强调色表示。下方功能操作使用倾斜游戏底板；继续用蓝色、保留原话生成用黄色、其他操作用中性底。默认只露出主操作与“更多操作”，旧版宽厚按钮退出此区域。

## 首页轮廓

- 最近动态共用一个 12 px 圆角外框，条目首尾衔接外框，最后一行不画底部分隔线；空状态使用同样轮廓。
- 左侧角色／会话条目使用 10 px 圆角，左右各留 8 px，条目之间保留间隔。
- 悬停、当前角色与键盘焦点分别提供柔和底色、强调色标记和清晰焦点环。

## 设置卡片

按用户明确的回退目标，设置分类、快捷控件、功能入口和外层分组恢复到引入游戏菜单按钮之前的平面样式。第一轮的 9 px 圆角、2 px 白边、3 px 凸起底边，以及后续加深底板的试点均撤回；颜色、间隔与圆角沿用原有设置样式，输入框和开关保持原形态。

“重新检测”等次要设置动作恢复此前的中性游戏底板，主要配置动作继续使用原有蓝色按钮。首页圆角、聊天圆形按钮和其他既有改动保持不变。

保留已下载并套用的原始 `Common_Reward_Deco` 标题装饰及黄色下划线；原设计文档继续保留。

## 实现与回退

表现层集中在 `public/css/dreamland-game-controls.css`，保留既有 DOM、事件和点击逻辑。这轮不新增外观偏好或数据格式；回退只需恢复这轮样式改动，无需迁移用户数据。
