# DreamLand UI 设计规范草案

版本：v0.3 · 日期：2026-10-04 · 状态：供用户细化与后续开发参考。

本规范基于当前 MomoTalk / BA 界面的实际代码，以及用户已确认的回退结果与导航素材方案。它整理现状，并给新增 UI 提供构建方法。标为“新增约束”的条目属于草案建议，不代表所有旧组件已完成改造。

原 [设计基线](design.md)、[外观说明](dreamland-appearance.md) 保留原文。两份文档含早期设计方向、旧按钮配色及旧素材数量，不能直接作为当前视觉实现的截图依据。当前视觉冲突先按用户最新指令和已核对的实现处理，再同步本草案，不能根据历史试点重新改回已撤销的效果。

## 1. 设计方向与已确认边界

界面采用粉色 MomoTalk 品牌页头、固定玫瑰红选择色、低对比灰色画布、白色内容面板和本地游戏图标。游戏感集中在字标、图标、标题装饰和主要动作上，信息区以阅读与操作为先。

- 保留桌面左侧会话、右侧聊天或完整功能页的骨架。
- 保留首页动态外框与联系人条目的圆角优化。
- 保留聊天头部的圆形图标工具。
- 底部入口从左到右固定为“首页、聊天、朋友圈、工坊、设置”。关于入口位于设置分类中，并提供返回设置按钮。
- 首页展示登录后的问候与活动面板；切换到首页不能关闭或清空当前会话。聊天入口保留当前会话及草稿，尚无活动会话时按时间恢复最近的原生角色或群聊。
- 导航使用用户指定的彩色 Message / Social / Replay / Setting 原图；首页使用用户确认并摆正后的蓝白房屋图。图标以 contain 等比显示，不能用单色 mask 丢失原色或通过拉伸改变比例。
- **设置分类、快捷控件、功能行与分组卡片使用回退后的平面样式。不得重加游戏菜单的 2 px 白边、3–4 px 凸起底边、深灰承托底板或内衬托盘。**
- 功能页标题统一使用回退后的浅色渐变、低透明度底纹与黄色短下划线；设置不再单独使用蓝色三角试点装饰。
- 倾斜按钮按用途选择，不因控件“在设置页”就全部倾斜；现存例外明确登记，不扩散到新增控件。

## 2. 从规则到页面的构建顺序

`页面任务 → 语义颜色与尺寸 → 复用组件 → 页面布局 → 交互状态 → 明暗/手机验收`

1. 先确定本页主要任务，例如继续聊天、调整连接、编辑角色。一个局部操作区只突出一个主动作。
2. 选择已有的语义变量与尺寸，不从某张游戏截图重新发明整套样式。
3. 复用页头、列表、表单、图标按钮、主动作、提示区等已有组件。
4. 先排信息层级，再决定装饰；留白、薄分隔线和底色优先承担分组。
5. 为组件补齐默认、悬停、焦点、选中、加载、禁用、错误等有意义的状态。
6. 使用合成数据验收桌面、窄窗口、手机和暗色；涉及导航时核对草稿保留和返回路径。

## 3. 颜色：按语义取值

下表为当前主样式的基础值，最终颜色可能由选中混色、控件素材或透明遮罩合成。组件 CSS 应引用变量，不直接复制最终像素颜色。

| 语义 / 变量 | 亮色 | 暗色 | 使用位置 |
| --- | --- | --- | --- |
| 选择强调 `--dl-accent` | `#B94362` | `#F2B2C5` | 选中导航、状态标记、文字强调 |
| 强强调 `--dl-accent-strong` | `#96304C` | `#FFD2DE` | 需要更明确对比的强调文字 |
| 页面画布 `--dl-canvas` | `#E9EAEC` | `#211F23` | 内容区背景 |
| 内容表面 `--dl-surface` | `#FFFFFF` | `#2D292F` | 页头、面板、工具按钮 |
| 次级表面 `--dl-soft` | `#F3F4F5` | `#28242A` | 列表底、设置行、提示区 |
| 正文 `--dl-text` | `#354252` | `#F4EDF0` | 标题、正文、图标 |
| 次要文字 `--dl-muted` | `#687584` | `#C8BCC3` | 描述、辅助说明 |
| 分隔线 `--dl-border` | `#D7DCE2` | `#4C424A` | 薄边框和分隔线 |
| 品牌页头 `--ba-header` | `#F28CA2` | `#5D3D4A` | 聊天和品牌栏 |
| 用户消息 `--dl-outgoing` | `#B94362` | `#6E4858` | 出站气泡及相关混色 |

蓝色和黄色是**动作素材的专用色**：蓝色用于创建、生成、发布和主要配置动作；黄色用于继续、确认等突出动作。它们不替代玫瑰红选择色，也不新增蓝色全局主题。按钮文字分别采用当前深蓝灰或深褐色，不能把深色正文直接压到深色纹理上。

新增约束：普通文字以至少 4.5:1 的对比度为验收目标；大字号与关键图形以至少 3:1 为目标。状态必须同时有文字、图形或数量，不仅靠颜色。当前旧组件的低对比问题应单独记录和修复，不能宣称已有组件全部达标。

## 4. 字体与信息层级

当前 UI 使用本地 `DreamLand UI Rounded CN`，回退为 Noto Sans、微软雅黑或系统无衬线字体；正文和界面文字保持同一体系。代码使用等宽字体，Font Awesome 图标保留自己的图标字体。

| 内容 | 当前参考值 / 新增建议 |
| --- | --- |
| 首页主标题 | 当前自适应 `22–30 px`，粗体 |
| 页头标题 | 当前聊天角色名约 `18 px`；新增功能页沿用现有同类页头 |
| 区块标题 | 新增建议 `16–20 px`，600–700 字重 |
| 消息正文 | 当前 `15 px`，约 `1.75` 行高 |
| 表单、按钮文字 | 新增建议 `13–14 px`，主动作 600–700 字重 |
| 描述、时间、次级标签 | 新增建议 `11–12 px`；既有紧凑导航存在更小值，不据此继续缩小新文字 |

长标题允许换行或省略，并保留完整可读名称。正文不能因为排版不足就缩小；中英文混排、长 URL、JSON、Markdown 和代码块均要保留选择与复制能力。

## 5. 页面骨架与响应式

| 区域 | 当前规则 | 开发含义 |
| --- | --- | --- |
| 桌面会话栏 | `clamp(326px, 28vw, 390px)` | 搜索、筛选、会话、连接状态、底部导航共用此栏 |
| 桌面统一页头 | 固定 `60 px`，border-box | 首页、聊天、朋友圈、工坊、设置与左侧品牌栏上下边缘对齐，内部文字不能撑高外框 |
| 聊天阅读区 | 最大 `1280 px`；气泡上限 `1160 px` | 输入区和消息共用水平边界，不各自偏移 |
| 桌面设置 | 分类栏 `210–260 px`；主内容约 `900 px` 上限 | 左侧保留会话栏，设置占完整右侧区域 |
| 桌面底部导航 | 高度约 `68 px`；手机 `64 px + 底部安全区` | 固定五个入口；图标在 `38 × 32 px` 区域等比显示 |
| 手机断点 | `≤700 px` | 会话/聊天切换；设置分类和内容分步显示 |
| 手机聊天头部 | 两行控制区，最小约 `104 px` 加安全区 | 两条世界线及对应新建入口仍可达 |
| 手机功能页 | 占可用主区域，底部导航保留 | 不压缩成多栏桌面页面 |

现有 `1000 px` 和 `380 px` 附近的收紧规则继续保留，不另起一套互相冲突的断点。建议验收宽度：1920、1280、853、390、320 px。

MomoTalk 字标使用原始 `256 × 64 px` 纹理，显示为 `144 × 36 px`，保持 4:1 比例。密度通过间距调整，不对整个界面、字标或图标做纵向缩放。

设置恢复原有分类栏和内容栏布局，撤销跨栏页头背景试点；标题使用与工坊相同的浅色装饰。

### 工坊随机入口与朋友圈布局

- 工坊随机角色卡入口位于页头下方右侧，蓝色圆底 `56 × 56 px`，使用原始 CardShop 图。悬停或键盘焦点进入该操作区时，向下显示 `44 × 44 px` 的 MinigameOption 偏好按钮；手机直接显示两个按钮。
- 偏好复用现有角色字段，并提供“必须包含”“必须排除”。已选内容作为约束，其余内容由模型构思；偏好按用户空间独立保存，版本校验失败回退默认值，更新前保留上一份原始值。
- 点击随机入口复用创作简报、写作与审校流程。只输出文字角色卡及头像提示词，结果进入预览供编辑和人工保存；不覆盖普通工坊表单，不自动保存角色。运行中禁止重复触发。
- 朋友圈进入后先显示动态列表。模型、AI 热情程度及发布权限集中到页头“设置”侧栏，手机占满内容区域；后台运行状态用紧凑文字呈现。
- “发动态”及左侧“发布新动态”展开发布区，收起、切换页面时保留未提交的草稿。已有动态编辑仍使用同一发布区。设置面板与随机偏好面板支持关闭按钮和 Escape，并将焦点返回可见入口。

新增约束：常规间距优先从 `4 / 8 / 12 / 16 / 24 / 32 px` 选取；组件内部通常 8–12 px，区块内部 16–24 px，区块之间 16–24 px。既有 5、6、9、10 px 等紧凑值保持原位，不能为了“统一网格”批量改动已确认页面。

## 6. 控件按用途选择形状

| 控件 | 形状与当前表现 | 使用规则 |
| --- | --- | --- |
| 聊天头部记忆、更多、新建等图标工具 | `44 × 44 px` 圆形，薄边，图标居中 | 只承载紧凑工具操作；状态点保持可见 |
| 手机第二行新建入口 | 带线路文字的小圆角矩形 | 明确的文字例外，不能强制裁成圆形 |
| 确认、继续 | 黄色倾斜底板，文字正立 | 保留现有确认语义及点击区域 |
| 创建、生成、发布、主要配置 | 蓝色倾斜底板，文字正立 | 一个操作组中的主动作 |
| 普通取消、次要操作、首页快捷入口 | 规整中性矩形 | 不与主动作争夺视觉重点 |
| 设置分类和快捷表单项 | 平面小圆角、约 `1 px` 薄描边，分类/快捷项当前 `6 px` 圆角 | **无新增白边、实体底边或承托托盘** |
| 设置分组和详情卡片 | 当前约 `8 px` 圆角、薄边、无凸起阴影 | 只表示内容分组，不模拟实体按钮 |
| 输入框、下拉框 | 当前约 `5 px` 圆角，常用高度至少 `44 px` | 保持原生输入形态与键盘行为 |
| 互斥模式 | 分段控件，选中滑块 | 同类选项在同一控件内；不能拆成多个圆形按钮 |
| 头像 | 会话头像圆形；首页常用角色使用既有切角边框 | 两种语境不同，不机械统一 |

现存例外：设置里的“重新检测”等 `.leslie-settings-secondary-button` 已恢复此前的倾斜中性游戏底板。保留该兼容表现，不因此给设置分类、下拉框和全部次要按钮加倾斜样式。弹窗关闭沿用既有游戏关闭图形，不强制加一圈白底。

倾斜效果由背景伪元素或九宫格素材承担；按钮文字、焦点和点击布局不旋转、不倾斜。较小的纸飞机发送图标仍是提交动作，保留现有游戏底板，不改成普通圆形工具。

## 7. 列表、圆角与层级

- 联系人条目：当前 `10 px` 圆角，左右各留 `8 px`；选中使用粉色混色和既有状态表达，不新增厚底边。
- 首页最近动态：共用 `12 px` 外框；首尾条目衔接外框，最后一行无底部分隔线；空状态使用相同轮廓。
- 聊天气泡：复用已有 NGUI 九宫格、左右归属和暗色适配，不重新绘制尾部或改动消息 DOM。
- 设置的介绍卡片等既有尺寸例外沿用当前实现；不要把所有容器强制改成一种圆角。
- 内容面板优先使用薄边、底色与留白。全屏功能页不模拟浮起的模态窗口；确有菜单或弹窗时再表达层级。
- 普通圆形工具当前可有极轻的 2 px 底部阴影；这不授权给设置卡片加凸起菜单底边。

## 8. 装饰、背景与素材

页头装饰停留在标题区。所有功能标题包括设置恢复浅色渐变与 0.12 透明度的按钮纹理，黄色短线统一约 `48 × 4 px`。撤销 Common_Top_Menu_Bg 和设置 Common_Reward_Deco 标题试点、额外右移及跨栏背景；保留原有标题间距与 60 px 对齐高度。新增页面不得重新套用已撤销的装饰。

首页场景和聊天背景保持独立开关。聊天柔和模式与清晰模式目前分别使用约 82% 和 42% 的画布混色遮罩；关闭背景必须真正隐藏场景，不能残留遮罩、布局空位或不可点击覆盖层。

素材取用顺序：已有运行素材 → 大素材库检索 → 明确必要时新增适配。图片缺失时回退到文字、系统字体或已有图标，不锁定聊天。

- 运行素材：[素材说明](../public/img/blue-archive/ASSETS.md)、[来源账目](../public/img/blue-archive/sources.json)。
- 完整开发库：[素材库说明](../resources/blue-archive/README.md)。
- 本机平铺浏览位置：`resources/blue-archive/ui-library/1.93.454564/全部图片_平铺/`；所选文件对应 `_素材来源索引.csv`。此目录忽略且不进入应用运行包。
- 选用后在运行账目登记名称、来源、裁切/适配和哈希；仅复制实际需要的文件，不把 7,212 张浏览素材全部加入页面请求。

## 9. 状态与交互

| 状态 | 构建要求 |
| --- | --- |
| 默认 | 同类组件具有相同文字层级、对齐方式和边界 |
| 悬停 | 轻微混色或亮度变化；不让布局跳动 |
| 键盘焦点 | 清晰强调色焦点环；伪元素按钮须让焦点作用在可见背景上 |
| 选中 | 背景加文字/图标或 `aria-pressed`；与悬停可区分 |
| 加载 | 明确正在处理的对象；防止重复提交，保留无关控件可用 |
| 禁用 | 用真实 `disabled` / 合适语义表达，不能只改变透明度 |
| 空状态 | 说明当前无内容，并提供相关下一步，不塞入无关演示内容 |
| 错误/断线 | 写清失败对象和重试入口，不丢失已有草稿 |

新增约束：图标操作具有可读名称与提示；新手机触控目标至少 `44 × 44 px`。现有紧凑分段控件和弹窗小关闭按钮不是新增组件的尺寸示范，需要单独验收触达能力。

当前分段滑块位移动画约 220 ms、透明度约 150 ms；其他新增反馈建议 120–220 ms。减少动态时取消非必要移动、缩放和动画；不增加持续装饰动画。

## 10. 实现位置与兼容要求

| 内容 | 当前主要位置 |
| --- | --- |
| 色彩、聊天骨架与素材气泡 | `public/css/dreamland-blue-archive.css` |
| 整页导航、功能页与手机布局 | `public/css/dreamland-pages.css`、`public/scripts/dreamland-pages.js` |
| 按钮形状、圆形工具、标题装饰、首页圆角、字体 | `public/css/dreamland-game-controls.css` |
| 紧凑纵向间距、导航彩图、独立首页布局 | `public/css/dreamland-compact.css`；导航彩图规则位于 `dreamland-game-controls.css` |
| 设置原有表单与分类 | `public/css/leslie-settings.css`、`public/scripts/leslie-settings.js` |
| 主题偏好 | `public/scripts/leslie-theme.js` |
| 素材读取与失败恢复 | `public/scripts/dreamland-ba-assets.js` |

`public/index.html` 的实际样式加载顺序和最终选择器优先级是判断像素表现的依据。不要只读早期基础样式就把后加载的规则误判为未实现。

新增约束：按组件和页面作用域修改，不用宽泛的 `button` / `div` 覆盖全部控件，不通过不断追加 `!important` 解决设计冲突。能复用既有 DOM 与监听器就复用；若必须改变组件结构，先核对事件、焦点、草稿和返回行为。

UI 变更不得改变角色卡兼容、JSONL、群聊、World Info、Swipe、消息生成或模型适配。身份、记忆、朋友圈和语音不可用时，普通聊天仍可使用。图标、字体和背景加载失败同样应保留操作能力。

## 11. 后续开发验收清单

- [ ] 新组件采用本规范的语义变量，并核对明暗实际对比。
- [ ] 按钮形状与操作用途匹配，既有例外没有被扩散。
- [ ] 设置分类和表单保持平面薄边；未重新引入游戏菜单凸起样式。
- [ ] 页头、主内容和输入区对齐，中文/英文长文本不会挤掉控件。
- [ ] 320/390 px 无整页横向溢出，软键盘与安全区不会遮住输入区。
- [ ] 键盘焦点、选中、加载、禁用和错误反馈可识别；状态不只依赖颜色。
- [ ] 导航、返回和世界线切换保留原草稿；原生功能仍可到达。
- [ ] 缺图、缺字体、未连接状态有可用回退。
- [ ] UI 验收使用合成角色、聊天和配置；不把用户截图或私人数据提交到仓库。
- [ ] 运行最窄相关验证；仓库级交付按仓库指令执行检查、lint 和相关测试，并记录未完成的人工验收。

## 12. 后续细化与使用

后续 UI 开发先阅读本文，按第 2 节的构建顺序推进，并使用第 11 节验收。精确尺寸先核对标记为当前值的内容与对应源码；新增建议在用户细化后同步更新，不能当作批量重做已有界面的授权。

下一版可继续细化：不同功能页的密度、字号下限、所有状态的对比度、紧凑控件触达范围、记忆/朋友圈/工坊的组件复用。新增设计方向应先试点一个区域并由用户验收，再考虑推广。
