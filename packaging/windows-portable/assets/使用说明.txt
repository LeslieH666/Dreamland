DreamLand Windows x64 懒人便携版
====================================

一、启动

双击“启动 DreamLand.cmd”。首次启动需要初始化空白数据，可能比以后稍慢。
程序已内置 Electron、Node.js、Chromium 和生产依赖，不需要另外安装 Node.js 或 npm。

二、关闭

关闭 DreamLand 窗口后，程序会留在系统托盘并继续处理朋友圈互动。需要完全退出时，请在托盘菜单选择“退出 DreamLand”，也可以双击“关闭 DreamLand.cmd”。
关闭脚本只会处理本便携包记录的主进程，不会批量结束电脑上的其他 Electron 程序。

三、用户数据

所有角色卡、聊天、世界书、设置、API 密钥和 Leslie 记忆都保存在“UserData”目录。
本包不含制作者的私人角色、聊天、账号、API 密钥或记忆数据。
移动到另一台电脑时，应在程序完全关闭后复制整个 DreamLand 文件夹。

四、备份

先关闭程序，再双击“备份用户数据.cmd”。备份 ZIP 会进入“Backups”目录。
恢复时先关闭程序，把当前 UserData 改名保留，再将备份内容解压回 UserData。

五、日志和排错

双击“查看运行日志.cmd”打开 Logs 目录。启动失败时优先查看最新的 stderr.log 与 stdout.log。
程序只监听本机 127.0.0.1:8127，不提供局域网或三端同步功能。

六、模型连接

首次使用需要在 DreamLand 的“设置 → 模型连接”中填写自己的 API 地址、密钥与模型。
这些信息只保存在当前便携包的 UserData 中。
连接状态会区分“正在检测、已连接、已配置、未连接”；只有接口实际验证成功才会显示“已连接”。

“思考模式”默认关闭。关闭时，兼容接口会收到直接回答/禁用思考的请求，也不会在聊天中显示隐藏思考；修改只影响之后的新回复，不会改动角色卡和已有聊天。
如果某个第三方服务仍强制思考，说明该服务或模型忽略了关闭参数，应在同一页改用它提供的非思考模型版本。

七、系统要求

Windows 10/11 x64。建议将整个目录放在普通可写位置，不要放入 Program Files。
杀毒软件可能对未签名的自制 Electron 程序给出提示；请通过 SHA256SUMS.txt 核对核心文件。
